## 6. 기기 알림 설정 API 연결

- 관리자 기기 알림 설정 API 함수를 추가했다.
- 추가 함수:
  - `getAdminDeviceNotice(deviceNo)`
  - `setAdminDeviceNotice(option, param)`
- 화면 선택값 `notiCd`를 백엔드 `option` 값으로 변환해 전송하도록 처리했다.
- `adminId`는 프론트에서 전송하지 않고 백엔드 인증 컨텍스트 기준으로 처리되도록 유지했다.

옵션 매핑:

| notiCd | option | 의미 |
| --- | ---: | --- |
| 빈 값 | 100 | 알림 해제 설정 취소 |
| NC00 | 0 | 내일 오전 9시까지 알림 해제 |
| NC03 | 3 | 3시간 알림 해제 |
| NC06 | 6 | 6시간 알림 해제 |
| NC12 | 12 | 12시간 알림 해제 |
| NC99 | 99 | 다음 설정 시까지 알림 해제 |
