# 보호자 계정 상태 UI 및 탈퇴 Pending 정책 반영

작성일: 2026-06-08

## 작업 범위

- 사용자 관리 목록의 계정상태 검색 및 표시를 `N/H/S/P` 기준으로 정리했다.
- 사용자 상세 팝업의 계정상태 선택에서 `D`를 제거하고, Admin 허용 전환을 `N -> S`, `S -> N`으로 제한했다.
- 탈퇴 Pending(`P`) 상태는 표시만 가능하며 Admin 화면에서 복구하거나 직접 선택할 수 없게 했다.
- 사용자 상세의 삭제 버튼 stub을 제거했다.

## API 의존성

- 기존 Admin API 모듈의 `selGuardianListByAdmin`, `getGuardianInfo`, `updGuardianByAdmin` 흐름을 유지했다.
- 목록/상세는 기존 `accountState` 값을 기준으로 동작한다.
- 목록 표시명은 `accountStateName` 또는 `ACCOUNT_STATE_NAME`이 내려오면 우선 사용하고, 없으면 Admin fallback(`정상/휴면/정지/탈퇴`)을 사용한다.
- 신규 탈퇴/복구/하드삭제 API는 추가하지 않았다.

## 검증 기준

- 목록 검색 필터에서 `D`가 보이지 않고 `S`, `P` 검색이 가능해야 한다.
- 목록 계정상태는 `N/H/S/P`를 각각 `정상/휴면/정지/탈퇴`로 표시해야 한다.
- 상세 계정상태에서 `D`를 선택할 수 없어야 한다.
- `P` 계정은 상세에서 상태 select가 비활성화되어 복구할 수 없어야 한다.
- `N` 계정은 `S`, `S` 계정은 `N`으로만 전환할 수 있어야 한다.
- 탈퇴/복구/하드삭제 화면이나 버튼이 없어야 한다.

## 잔여 확인

- API 서버가 Admin 상태 수정에서 `N -> S`, `S -> N`만 허용하고 `D/P` 저장을 거부하는지 최종 확인이 필요하다.
- API가 계정상태 코드 목록 또는 `accountStateName`을 내려주는 경우, 현재 fallback과 표시명이 동일한지 확인이 필요하다.
